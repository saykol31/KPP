K++

Compilador nativo para KolibriOS · Native compiler for KolibriOS · Компилятор для KolibriOS

K++ es un lenguaje de programación y su compilador para KolibriOS, el sistema operativo x86 bifurcado de MenuetOS. Traduce programas .kpp a ejecutables nativos de KolibriOS con cabecera MENUET01: sin intérprete y sin runtime externo, del fuente al binario plano x86.
