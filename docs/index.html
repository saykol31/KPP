K++

Compilador nativo para KolibriOS · Native compiler for KolibriOS · Компилятор для KolibriOS

K++ es un lenguaje de programación y su compilador para KolibriOS, el sistema operativo x86 bifurcado de MenuetOS. Traduce programas .kpp a ejecutables nativos de KolibriOS con cabecera MENUET01: sin intérprete y sin runtime externo, del fuente al binario plano x86.

Repositorio en GitHub Manual del lenguaje (PDF, v1.0)

Estado

Stage 0 — completo. El compilador escrito en C++, con frontend propio (lexer, parser, analizador semántico), representación intermedia (IR), backend x86 y escritor de ejecutables. Su batería de pruebas pasa entera: 60 positivas, 11 negativas, 0 fallos.

Stage 1 — en curso. El compilador reescrito en el propio K++ (autohospedaje). Su primera pieza, el lexer, ya compila con Stage 0 y corrió en KolibriOS real: prueba de campo aprobada el 2026-11-11 (27 tokens, 0 errores).

In English

K++ is a programming language and its native compiler for KolibriOS. It compiles .kpp source files into flat native executables (MENUET01 header) — no interpreter, no external runtime. The C++ compiler (Stage 0) is complete; the self-hosting rewrite in K++ itself (Stage 1) is under way, and its lexer has already run on real KolibriOS. Source, tests and the Spanish language manual live in the GitHub repository.

По-русски

K++ — язык программирования и его родной компилятор для KolibriOS. Программы .kpp переводятся в плоские исполняемые файлы (заголовок MENUET01) без интерпретатора и внешнего рантайма. Компилятор на C++ (Stage 0) завершён; идёт переписывание на самом K++ (Stage 1, self-hosting) — лексер уже работает в настоящем KolibriOS. Исходники, тесты и руководство — в репозитории на GitHub.
